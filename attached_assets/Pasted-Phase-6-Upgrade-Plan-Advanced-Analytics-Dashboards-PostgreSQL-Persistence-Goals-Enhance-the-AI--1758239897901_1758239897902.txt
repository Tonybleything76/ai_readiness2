Phase 6 Upgrade Plan: Advanced Analytics Dashboards + PostgreSQL Persistence

Goals:
Enhance the AI Readiness Assessment application with enterprise analytics dashboards (progress tracking, benchmarking, comparisons) and migrate development MemStorage to full PostgreSQL persistence for production readiness.

Tasks:

1) PostgreSQL Persistence
- Replace MemStorage with PostgreSQL (using Drizzle ORM).
- Update schema to include proper indexing for:
  - orgName
  - industry
  - createdAt
- Implement database migrations.
- Ensure seeding works for demo data (sample orgs, industries).
- Update /api/responses and /api/score endpoints to use Postgres instead of in-memory storage.
- Add automated backup script (cron-compatible) to dump DB to a file.

2) Organization Analytics
- Add endpoint GET /api/org/:orgName/history
  → Returns all historical assessments for that organization.
- Frontend: Add “Progress” tab on results page with:
  - Line chart of overall readiness over time.
  - Pillar trend lines (toggleable).
- Ensure time-series visualization works for multiple assessments.

3) Industry Benchmarking
- Add endpoint GET /api/benchmark/:industry
  → Returns medians, quartiles, and percentiles for overall + per-pillar scores.
  → Enforce k-anonymity (only return if ≥ 10 responses).
- Frontend: On results page, show:
  - Radar chart overlay (user vs industry median).
  - Percentile badge for overall readiness.
  - Heatmap (optional): pillar readiness vs. industry average.

4) Super Admin Analytics Dashboard
- New route: /admin/analytics
- Display:
  - Table of industries with average scores.
  - Downloadable CSV/JSON of aggregated analytics.
  - Cross-org comparison chart (bar chart of top 10 orgs).
- Backend: Add analytics service to compute aggregated stats efficiently (with caching).

5) Documentation
- Update README with:
  - Postgres setup + migration instructions.
  - How to run analytics endpoints.
  - New admin analytics dashboard features.
  - Screenshots of analytics visualizations.

Acceptance Criteria:
✅ MemStorage replaced with Postgres persistence for responses.
✅ Historical tracking works: orgs can view progress over time.
✅ Benchmarking works: industry medians + percentiles returned and displayed.
✅ Super Admin analytics dashboard functional with cross-org comparisons.
✅ README updated with database + analytics instructions.
