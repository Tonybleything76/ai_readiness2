Phase 2 Upgrade Plan: UX Polish + Admin Dashboard Foundation

Goal:
Enhance the AI Readiness Assessment app’s user experience and add an admin interface for reviewing responses. Build on top of the completed MVP + persistence system.

Tasks:

1) UX / Frontend Polish
- Assessment Wizard:
  - Add a progress bar (shows pillar completion %).
  - Smooth transitions between steps (use Framer Motion or simple fade).
  - Auto-save progress to localStorage and restore on reload.
- Results Page:
  - Add a "Download PDF" button with print-friendly stylesheet (≤ 2 pages).
  - Improve mobile responsiveness for radar + gauge charts.
  - Show timestamp + orgName + industry at top of results.

2) Admin Dashboard (Foundational)
- Route: `/admin`
- Simple login prompt with hardcoded password from env variable ADMIN_PASS.
- Once logged in, display table of responses (id, createdAt, orgName, industry, overall).
- Add "View" button to expand a single response:
  - Show pillar scores
  - Show category
  - Show answers (collapsed by default).
- Add export options:
  - Download all responses as CSV
  - Download single response as JSON

3) API Enhancements
- Add `GET /api/responses` (admin only) → returns paginated list of responses.
- Add `GET /api/export/csv` → downloads all responses as CSV.
- Ensure admin routes are protected by middleware that checks ADMIN_PASS.

4) Documentation
- Update README with:
  - New admin login instructions (set ADMIN_PASS in environment).
  - How to use the PDF export feature.
  - Screenshots or notes on progress bar + UX improvements.

Acceptance Criteria:
✅ Wizard shows progress bar, smooth transitions, auto-save state.
✅ Results page can export to PDF, includes org metadata.
✅ `/admin` route exists with password protection and lists responses.
✅ Admin can view individual responses and export data as CSV/JSON.
✅ README updated with new features.

Please implement these upgrades step by step, then confirm when the UX improvements and admin dashboard are fully functional.
