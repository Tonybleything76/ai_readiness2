Phase 3 Upgrade Plan: Historical Tracking + Benchmarking + Insights

Goal:
Enhance the AI Readiness Assessment app with advanced analytics. Allow organizations to track their readiness over time, compare against industry benchmarks, and receive insights/recommendations for low-scoring pillars.

Tasks:

1) Historical Tracking
- Update database schema:
  model Response {
    id           String   @id @default(cuid())
    createdAt    DateTime @default(now())
    orgName      String?
    industry     String?
    answersJson  Json
    pillarScores Json
    overall      Float
    category     String
  }
- Ensure multiple responses can exist per orgName.
- Add endpoint GET /api/responses/:orgName to retrieve all assessments for that organization.
- Frontend: Add a “History” tab on results page showing:
  - Line chart of overall scores over time.
  - Per-pillar trend lines (small multiples or toggleable).

2) Benchmarking
- Add endpoint GET /api/benchmark/:industry that computes:
  - Median and quartiles of overall and per-pillar scores for that industry.
  - Number of orgs in dataset (apply k-anonymity: only return if ≥ 10 responses).
- Frontend: On results page, display:
  - Comparison of user’s overall vs. industry median.
  - Overlay industry median line on radar chart.
  - Percentile ranking of user’s overall score.

3) Insights & Recommendations
- Create a new service /backend/insights.ts that maps pillar scores to recommendations:
  Example (rule-based):
    if score < 40 and pillar == "Data Management":
      → “Establish a central data governance council to improve oversight.”
    if score < 40 and pillar == "Culture":
      → “Run AI awareness workshops to improve adoption.”
- Add recommendations array to response payload in POST /api/score.
- Frontend: Show recommendations under the results visualization in a collapsible section.

4) Documentation
- Update README with:
  - How historical tracking works.
  - API endpoints for benchmarking.
  - Where to configure/edit insights mapping file.
  - Screenshots of new visualizations.

Acceptance Criteria:
✅ Multiple assessments per orgName are stored and retrievable.
✅ History tab shows overall + per-pillar score trends over time.
✅ Benchmark API returns industry medians, displayed alongside user results.
✅ Percentile ranking is calculated and shown on frontend.
✅ Low-scoring pillars generate at least one recommendation from insights module.
✅ README updated with explanations of new features.

Please implement these upgrades step by step, ensuring backend endpoints are tested first, then frontend visualizations and insights rendering.
